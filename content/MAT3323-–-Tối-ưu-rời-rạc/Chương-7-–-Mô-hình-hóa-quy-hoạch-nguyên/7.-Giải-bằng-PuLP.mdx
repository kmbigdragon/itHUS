**PuLP** là thư viện Python dùng để viết các mô hình LP và MILP. Thư viện miễn phí, mã nguồn mở theo giấy phép MIT, và mặc định đi kèm bộ giải CBC. Có thể đổi sang bộ giải khác như Gurobi, CPLEX mà gần như không phải sửa mô hình.

Cài đặt bằng lệnh:

```bash
pip install "pulp<4"
```

**▸ ⚠️ LƯU Ý**

Code trong bài dùng cách viết `LpVariable.dicts` giống tài liệu môn học và đã chạy thử trên PuLP 3.3.2. Từ PuLP 4 có hai thay đổi: hàm này đổi thành `prob.add_variable_dicts` và bản cài mặc định không còn sẵn bộ giải CBC, nên `prob.solve()` sẽ báo lỗi không có bộ giải. Vì vậy ở đây ta cài bản dưới 4.

**▸ CÁCH DÙNG**

- Tạo bài toán: `LpProblem("Ten", LpMinimize)` hoặc `LpMaximize`.
- Tạo biến: `LpVariable.dicts("x", chi_so, can_duoi, can_tren, LpBinary)`.
- Thêm hàm mục tiêu: `prob += bieu_thuc`, không có dấu so sánh.
- Thêm ràng buộc: `prob += bieu_thuc <= gia_tri`, có dấu so sánh.
- Giải bằng `prob.solve()`, xem nghiệm bằng `x.varValue`.

**▸ VÍ DỤ 1: ĐỊA ĐIỂM CÓ GIỚI HẠN CÔNG SUẤT**

Chọn nơi đặt cơ sở trong $m$ vị trí, rồi phân $n$ sản phẩm vào các cơ sở sao cho công suất lãng phí nhỏ nhất. Sản phẩm $j$ cần $r_j$, mỗi cơ sở có công suất $C$.

**Biến:** $x_{ij} = 1$ nếu sản xuất $j$ tại $i$. $y_i = 1$ nếu đặt cơ sở tại $i$. $w_i$ là công suất lãng phí tại $i$.

$$
\begin{align*}
\min \quad & \sum_{i=1}^{m} w_i \\
\text{s.t.} \quad & \sum_{i=1}^{m} x_{ij} = 1, \quad j = 1, \dots, n \\
& \sum_{j=1}^{n} r_j x_{ij} + w_i = C y_i, \quad i = 1, \dots, m
\end{align*}
$$

```python
from pulp import *

REQUIRE = {1: 7, 2: 5, 3: 3, 4: 2, 5: 2}
PRODUCTS = [1, 2, 3, 4, 5]
LOCATIONS = [1, 2, 3, 4, 5]
CAPACITY = 8

prob = LpProblem("FacilityLocation", LpMinimize)

use_vars = LpVariable.dicts("UseLocation", LOCATIONS, 0, 1, LpBinary)
waste_vars = LpVariable.dicts("Waste", LOCATIONS, 0, CAPACITY)
assign_vars = LpVariable.dicts(
    "AtLocation", [(i, j) for i in LOCATIONS for j in PRODUCTS], 0, 1, LpBinary
)

prob += lpSum(waste_vars[i] for i in LOCATIONS)

for j in PRODUCTS:
    prob += lpSum(assign_vars[(i, j)] for i in LOCATIONS) == 1

for i in LOCATIONS:
    prob += (
        lpSum(assign_vars[(i, j)] * REQUIRE[j] for j in PRODUCTS) + waste_vars[i]
        == CAPACITY * use_vars[i]
    )

prob.solve()

for i in LOCATIONS:
    if use_vars[i].varValue > 0.5:
        print(i, [j for j in PRODUCTS if assign_vars[(i, j)].varValue > 0.5])
```

Tổng nhu cầu là 19 nên cần ít nhất 3 cơ sở, tức tổng công suất 24 và lãng phí tối thiểu 5. Kết quả có 3 cơ sở, chứa các nhóm sản phẩm $\{1\}$, $\{2, 3\}$, $\{4, 5\}$ hoặc một cách chia khác có cùng độ lãng phí.

**▸ VÍ DỤ 2: GIẢI SUDOKU**

Sudoku chỉ cần tìm một nghiệm chấp nhận được, nên hàm mục tiêu để bằng 0.

**Biến:** $x_{vrc} = 1$ nếu ô hàng $r$, cột $c$ điền số $v$.

**Ràng buộc:**
- Mỗi ô có đúng một số.
- Mỗi số xuất hiện đúng một lần trên mỗi hàng, mỗi cột, mỗi khối $3 \times 3$.
- Các ô đề bài đã cho thì cố định: $x_{vrc} = 1$.

```python
from pulp import *

N = range(1, 10)
Boxes = [
    [(3 * i + k + 1, 3 * j + l + 1) for k in range(3) for l in range(3)]
    for i in range(3) for j in range(3)
]

prob = LpProblem("Sudoku", LpMinimize)
x = LpVariable.dicts("x", (N, N, N), 0, 1, LpInteger)
prob += 0

for r in N:
    for c in N:
        prob += lpSum(x[v][r][c] for v in N) == 1

for v in N:
    for r in N:
        prob += lpSum(x[v][r][c] for c in N) == 1
    for c in N:
        prob += lpSum(x[v][r][c] for r in N) == 1
    for b in Boxes:
        prob += lpSum(x[v][r][c] for (r, c) in b) == 1

# Các ô đề bài cho: (số, hàng, cột)
givens = [
    (5,1,1), (6,2,1), (8,4,1), (4,5,1), (7,6,1), (3,1,2), (9,3,2), (6,7,2),
    (8,3,3), (1,2,4), (8,5,4), (4,8,4), (7,1,5), (9,2,5), (6,4,5), (2,6,5),
    (1,8,5), (8,9,5), (5,2,6), (3,5,6), (9,8,6), (2,7,7), (6,3,8), (8,7,8),
    (7,9,8), (3,4,9), (1,5,9), (6,6,9), (5,8,9),
]
for v, r, c in givens:
    prob += x[v][r][c] == 1

prob.solve()
print(LpStatus[prob.status])
for r in N:
    print(*[v for c in N for v in N if value(x[v][r][c]) == 1])
```
